A program that sums up 24 November 2026's world news in one image.

`main.ts` copies the pre-rendered front page (`entry.png`, drawn in code by
`draw_frontpage.py`) into the harness output directory. No network, no
randomness: the same bytes are written on every run.

## The image

1024×1024 PNG, 121,218 bytes, deterministic. Masthead names the day;
three lead stories with illustrations (Benghazi warship sinking, Nvidia
bringing back Huang, Hormuz tanker mines); a stats bar (96 drones,
700,000 Russian dead, 31% Nvidia jump, 26 killed in a factory fire,
7 naval drones, 3 tankers hit); 36 stories across 6 regions (Europe,
Middle East, Americas, Asia, Africa, Global); a world map strip.

Every story was verified against reporting from 24 November 2026.
